# Task

Three hidden transformation rules — Alpha, Beta, Gamma — each turn a sequence of integers into another sequence. Infer each rule from its examples.

## Rule examples

### Alpha
- `[1,6,8,7,2] -> [1,6,7,2]`
- `[5,6,2,8,1,4] -> [5,6,8,1]`
- `[2,4,8,8] -> [2,4,8]`
- `[8,2,7,5,8,7] -> [8,2,5,8]`

### Beta
- `[6,3,3,3,3] -> [6,3,3,3,3]`
- `[7,2,3] -> [7,7,2,3]`
- `[7,5,6,2] -> [7,7,5,6,2]`
- `[6,2,8] -> [6,2,8]`

### Gamma
- `[5,5,9,6,5,9,5] -> [5,0,5,4,9,-3,6,-1,5,4,9,-4,5]`
- `[7,7,8,9,8,7,4] -> [7,0,7,1,8,1,9,-1,8,-1,7,-3,4]`
- `[9,5,5,6,2,1] -> [9,-4,5,0,5,1,6,-4,2,-1,1]`
- `[6,9,8,1,8,7,5] -> [6,3,9,-1,8,-7,1,7,8,-1,7,-2,5]`

## Apply in chain
Apply the rules in order to the test input: first **Alpha**, then **Beta** on Alpha's result, then **Gamma** on Beta's result — i.e. `Gamma(Beta(Alpha(test)))`.

**Test input:** `[8,2,1,3,4]`

## Output
Output ONLY the final sequence as a JSON array of integers (e.g. `[1,2,3]`). No prose.
