# Tarefa

Três regras de transformação ocultas — Alpha, Beta, Gamma — cada uma converte uma sequência de inteiros em outra sequência. Infira cada regra a partir de seus exemplos.

## Exemplos das regras

### Alpha
- `[4,5,2,4,2,6] -> [4,5,4,6]`
- `[6,8,1,2,8] -> [6,8,2,8]`
- `[3,9,7,1] -> [3,9]`
- `[4,2,2] -> [4]`

### Beta
- `[1,8,6] -> [1,8,6,6]`
- `[6,4,6,1,2,3,1] -> [6,6,4,6,6,1,2,3,3,1]`
- `[5,3,5] -> [5,3,3,5]`
- `[8,3,3,4,7,1,7] -> [8,3,3,3,3,4,7,1,7]`

### Gamma
- `[9,5,1,3,5] -> [1,3,5,9,5]`
- `[7,4,4,4,4,1] -> [4,4,4,1,7,4]`
- `[2,8,4] -> [4,2,8]`
- `[7,8,1,6,3] -> [1,6,3,7,8]`

## Aplicar em cadeia
Aplique as regras em ordem à entrada de teste: primeiro **Alpha**, depois **Beta** sobre o resultado de Alpha, depois **Gamma** sobre o resultado de Beta — ou seja, `Gamma(Beta(Alpha(teste)))`.

**Entrada de teste:** `[7,3,6,5,7,1]`

## Saída
Retorne SOMENTE a sequência final como um array JSON de inteiros (ex.: `[1,2,3]`). Sem texto.
