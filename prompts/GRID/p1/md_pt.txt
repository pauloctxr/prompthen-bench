# Tarefa

Cada exemplo mostra uma grade de entrada transformada em uma grade de saída por uma única regra oculta. As grades são matrizes de dígitos 0-9 (0 é o fundo). Infira a regra a partir dos exemplos, depois produza a grade de saída para a entrada de teste.

## Exemplos

### Exemplo 1
Entrada:
```
3 3 0
2 0 0
3 2 1
2 0 0
0 3 0
```
Saída:
```
6 3 6
2 6 6
3 2 1
2 6 6
3 3 6
```

### Exemplo 2
Entrada:
```
3 3 3 3 2
0 0 3 3 0
0 0 2 2 0
2 0 1 1 0
```
Saída:
```
3 0 0 2
3 0 0 0
3 3 2 1
3 3 2 1
2 0 0 0
```

### Exemplo 3
Entrada:
```
1 0 3 1 1
3 2 0 3 0
1 0 1 2 2
```
Saída:
```
1 3 1
0 2 0
3 0 1
1 3 2
1 0 2
```

### Exemplo 4
Entrada:
```
3 0 3 1 0
2 0 3 0 1
1 0 0 0 0
```
Saída:
```
3 2 1
0 0 0
3 3 0
1 0 0
0 1 0
```

## Entrada de teste
```
1 2 1
2 3 3
2 0 2
```

## Saída
Retorne SOMENTE a grade de saída de teste como um array JSON de arrays de inteiros (ex.: `[[1,2],[3,4]]`). Sem texto.
