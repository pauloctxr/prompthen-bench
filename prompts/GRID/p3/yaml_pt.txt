tarefa: Infira a unica regra oculta que mapeia cada grade de entrada para sua grade de saida, depois produza a grade de saida para a entrada de teste. As grades sao matrizes de digitos 0-9 (0 e o fundo). Retorne a grade de saida de teste como um array JSON de arrays de inteiros apenas.
exemplos:
  - exemplo: 1
    entrada:
      - "0 0 2 3"
      - "0 0 1 0"
      - "0 1 0 2"
    saida:
      - "0 0 0"
      - "1 0 0"
      - "0 1 5"
      - "5 0 3"
  - exemplo: 2
    entrada:
      - "0 2 3 3 0"
      - "3 0 2 1 0"
      - "0 0 0 1 0"
      - "3 0 0 2 1"
      - "2 1 2 0 0"
    saida:
      - "5 3 0 3 0"
      - "1 0 0 0 5"
      - "5 0 0 5 3"
      - "0 5 1 1 3"
      - "0 1 0 0 0"
  - exemplo: 3
    entrada:
      - "0 0 0 3"
      - "0 0 2 0"
      - "0 0 0 1"
      - "0 2 3 1"
    saida:
      - "4 0 0 0"
      - "0 2 0 0"
      - "1 0 0 0"
      - "1 4 2 0"
  - exemplo: 4
    entrada:
      - "2 0 1"
      - "3 0 2"
      - "0 0 2"
      - "0 0 3"
    saida:
      - "1 0 2"
      - "2 0 4"
      - "2 0 0"
      - "4 0 0"
entrada_de_teste:
  - "1 2 0 3"
  - "0 0 0 3"
  - "1 2 3 0"
  - "3 3 0 3"
  - "1 2 2 2"
saida: grade de saida de teste como array JSON de arrays de inteiros, ex. [[1,2],[3,4]], sem texto
