# VOLTGRID

VOLTGRID is a game on a circular tape of 8 cells (positions 0..7). Tokens carry a nonzero integer charge. State is a list of `[position, charge]` pairs sorted by position.

## Rules (per round, in order)
1. Every token moves one cell clockwise (position +1 mod N). Tokens landing on the same cell merge into one token whose charge is the sum.
2. Then, simultaneously for all tokens: any token with an immediately adjacent neighbor (distance 1 on the circle) of OPPOSITE-sign charge loses 1 of magnitude (keeps its sign).
3. (hidden rule — acts between rule 2 and rule 4; infer it from the example runs)
4. Finally, any token with charge 0 evaporates (is removed).

**The hidden rule 3 is fully visible in the example runs below — infer it.**

## Example runs
### Run 1 (tape size 8)
- initial: `[[5, 6]]`
- after round 1: `[[7, 6]]`
- after round 2: `[[1, 6]]`
- after round 3: `[[3, 6]]`

### Run 2 (tape size 8)
- initial: `[[7, 4]]`
- after round 1: `[[0, 4]]`
- after round 2: `[[1, 4]]`

### Run 3 (tape size 8)
- initial: `[[4, 4], [6, 3]]`
- after round 1: `[[0, 3], [5, 4]]`
- after round 2: `[[2, 3], [6, 4]]`
- after round 3: `[[4, 3], [7, 4]]`

## Test
Tape size 8, initial state `[[2, -2], [3, -1], [4, 6]]`. Simulate 3 rounds (documented rules + the hidden rule).

## Output
Output ONLY the final state as a JSON list of `[position, charge]` pairs sorted by position (e.g. `[[0,2],[5,-1]]`). No prose.
